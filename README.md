Laboratorio 2: Etapa de ganancia y calibración

Objetivo

Implementar y evaluar una etapa de amplificación no inversora para una señal simulada de pH.

Materiales

Arduino UNO

Amplificador operacional TL084

Resistencias de 10 kΩ

Capacitor de 10 µF

Protoboard y cables

Multímetro

Dos baterías de 9 V

Laptop con Arduino IDE

Archivos

codigo_pH.ino: código fuente utilizado en la práctica.

esquematico_circuito: esquema eléctrico del montaje.

Procedimiento general

Generar la señal simulada de pH mediante PWM y filtrarla con un circuito RC.

Implementar el buffer con el primer amplificador operacional.

Implementar el amplificador no inversor con ganancia teórica de 3.

Medir la salida y obtener la curva de calibración.
